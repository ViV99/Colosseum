```python
"""Fake ``ssh`` for the SSH-mode tests (SP5 T8.1): a Python script put first on PATH as ``ssh``.

Behaviour by ``FAKE_SSH_MODE`` (env): ``ok`` reports an allocated port, stores stdin until EOF, exits 0;
``exit`` reports the port, exits 3 once the installer end marker arrived; ``noport`` sleeps until killed;
``deny`` prints a publickey refusal and exits 255; ``node`` reads the stdin preamble and installer (up to the end
marker), then execs ``FAKE_SSH_NODE_ARGV`` (JSON argv; ``{hub}`` = the forward target of ``-R``) with the
preamble's variables, keeping the hub's stdin pipe (a stand-in for the remote installer + ``join``). Every start
writes ``argv-<n>.json`` into ``FAKE_SSH_DIR`` and (except ``node``) stdin into ``stdin-<n>.bin``.
"""
from __future__ import annotations

import json
import stat
import sys
from pathlib import Path

FAKE_PORT = 40123
END_MARKER = b"# colosseum-installer-end"

_SCRIPT = r'''#!PYTHON
import json, os, sys, time
from pathlib import Path
d = Path(os.environ["FAKE_SSH_DIR"]); d.mkdir(parents=True, exist_ok=True)
n = len(list(d.glob("argv-*.json"))) + 1
(d / f"argv-{n}.json").write_text(json.dumps(sys.argv[1:]))
mode = os.environ.get("FAKE_SSH_MODE", "ok")
if mode == "deny":
    sys.stderr.write("user@host: Permission denied (publickey).\n"); sys.stderr.flush(); sys.exit(255)
if mode == "noport":
    time.sleep(120); sys.exit(0)
fwd = sys.argv[sys.argv.index("-R") + 1]            # 0:<host>:<port>
host, port = fwd.split(":", 1)[1].rsplit(":", 1)
sys.stderr.write(f"Allocated port PORT for remote forward to {host}:{port}\n"); sys.stderr.flush()
if mode == "node":      # read the preamble and the installer, then become the "remote" node (keeps this stdin)
    env = dict(os.environ)
    while True:
        line = sys.stdin.buffer.readline()
        if not line:
            sys.exit(4)
        text = line.decode().strip()
        if text.startswith("COLOSSEUM_") and "; export " in text:
            import shlex
            key, value = text.split("; export ")[0].split("=", 1)
            env[key] = shlex.split(value)[0]
        if text.endswith("# colosseum-installer-end"):
            break
    argv = [a.replace("{hub}", f"{host}:{port}") for a in json.loads(os.environ["FAKE_SSH_NODE_ARGV"])]
    os.execvpe(argv[0], argv, env)
with open(d / f"stdin-{n}.bin", "wb") as out:
    while True:
        chunk = sys.stdin.buffer.read1(65536)
        if not chunk:
            break
        out.write(chunk); out.flush()
        if mode == "exit" and b"# colosseum-installer-end" in Path(out.name).read_bytes():
            sys.exit(3)
sys.exit(0)
'''


def install_fake_ssh(bin_dir: Path) -> Path:
    """Write the fake ``ssh`` into ``bin_dir`` (put ``bin_dir`` first on PATH, or pass the path as ``ssh``)."""
    bin_dir.mkdir(parents=True, exist_ok=True)
    path = bin_dir / "ssh"
    path.write_text(_SCRIPT.replace("PYTHON", sys.executable).replace("PORT", str(FAKE_PORT)))
    path.chmod(path.stat().st_mode | stat.S_IXUSR)
    return path


def starts(record_dir: Path) -> list[list[str]]:
    return [json.loads(p.read_text()) for p in sorted(record_dir.glob("argv-*.json"),
                                                        key=lambda p: int(p.stem.split("-")[1]))]


def stdin_of(record_dir: Path, n: int) -> bytes:
    path = record_dir / f"stdin-{n}.bin"
    return path.read_bytes() if path.exists() else b""


def env_for(record_dir: Path, mode: str) -> dict[str, str]:
    return {"FAKE_SSH_DIR": str(record_dir), "FAKE_SSH_MODE": mode}
```

```python
def _wait(predicate, timeout=20.0):
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        if predicate():
            return True
        time.sleep(0.02)
    return False
```

```python
"""SSH mode (SP5 spec block 2.2): the hub keeps one system ``ssh`` process per remembered SSH node.

``colosseum nodes add USER@HOST`` (or a line of ``--nodes hosts.txt``) makes the hub start
``ssh -T ... -R 0:<hub host>:<hub port> USER@HOST sh -s -- <join flags>``: the user's ``~/.ssh/config``, keys and
agent apply; ``BatchMode=yes`` (the hub cannot answer prompts), ``ExitOnForwardFailure=yes`` and
``LogLevel=INFO`` (ssh prints ``Allocated port N for remote forward to ...`` at INFO). Only the hub port is
forwarded, from a port the remote sshd allocates on the remote loopback; once ssh reports it, the hub writes the
stdin payload — a preamble that exports the token, the link id and the session flag, then the installer script
for ``127.0.0.1:<allocated port>`` (``bootstrap.installer.installer_script``) — and keeps ssh's stdin open: the
remote node agent watches its stdin (``SSH_SESSION_ENV``) and stops at EOF, so the remote node dies with the
link. A dead ssh is started again after a pause that doubles from ``SSH_BACKOFF_MIN_SEC`` to
``SSH_BACKOFF_MAX_SEC`` (reset after ``SSH_STABLE_SEC`` up).

Remembered SSH nodes live in ``ssh_nodes.json`` of the hub identity dir (``SshNodeBook``; one record per target,
0600): the hub starts every remembered node at the start of ``hub`` and ``train --listen`` (never plain ``train``),
until ``nodes remove``.

Threads: each link has two reader threads (ssh's stdout and stderr into the link's log file; the stderr reader
also looks for the allocated port and then writes the stdin payload); they post ``SshEvent`` through
``on_event`` (the hub inbox) and never touch hub state. ``SshLink.start`` / ``poll`` / ``stop`` run on the hub's
main loop thread only (Linux ``PR_SET_PDEATHSIG`` is bound to the thread that started ssh).

def check_target(target: str) -> str:
    """``user@host`` / ``host`` / ``user@[v6]`` as ``ssh`` takes it (a ``~/.ssh/config`` alias is a host);
    ValueError for anything else (an option, a port suffix, shell metacharacters)."""
    if not isinstance(target, str) or not _TARGET_RE.fullmatch(target) or target.startswith("-"):
        raise ValueError(f"SSH target {target!r}: expected user@host or host (use --ssh-opt Port=N for a port)")
    return target


def check_ssh_opt(opt: str) -> str:
    """One ``--ssh-opt`` value: ``Key=Value`` (passed as ``-o Key=Value``); ValueError otherwise."""
    if not isinstance(opt, str) or not _OPT_RE.fullmatch(opt):
        raise ValueError(f"--ssh-opt {opt!r}: expected Key=Value of an ssh option (e.g. Port=2222, "
                         f"IdentityFile=~/.ssh/id_lab), without spaces or quotes")
    return opt


@dataclass(frozen=True)
class SshNodeSpec:
    """One SSH node: what ``nodes add`` / a hosts-file line said, plus the hub's link id."""

    target: str
    workers: int | None = None
    evaluators: int | None = None
    name: str | None = None
    tags: tuple[str, ...] = ()
    ssh_opts: tuple[str, ...] = ()
    ssh_id: str = ""                   # 32 hex, chosen by the hub; the remote node reports it in Hello.ssh_id
    node_id: str | None = None         # the registered node with this ssh_id (set when its session opens)

    def __post_init__(self) -> None:
        check_target(self.target)
        for opt in self.ssh_opts:
            check_ssh_opt(opt)
        for what, value in (("workers", self.workers), ("evaluators", self.evaluators)):
            if value is not None and (isinstance(value, bool) or not isinstance(value, int) or value < 0):
                raise ValueError(f"SSH node {self.target}: --{what} must be an integer >= 0, got {value!r}")
        if self.name is not None and not _NAME_RE.fullmatch(self.name):
            raise ValueError(f"SSH node {self.target}: --name {self.name!r}: letters, digits, '_', '.', '-'")
        for tag in self.tags:
            if not _TAG_RE.fullmatch(tag):
                raise ValueError(f"SSH node {self.target}: tag {tag!r}: letters, digits, '_', '.', ':', '-'")
        if self.ssh_id and not _SSH_ID_RE.fullmatch(self.ssh_id):
            raise ValueError(f"SSH node {self.target}: malformed ssh_id {self.ssh_id!r}")

    @property
    def host(self) -> str:
        return self.target.rsplit("@", 1)[-1].strip("[]")

    @property
    def display_name(self) -> str:
        """The node name the link asks for: ``--name``, else the host (sanitized)."""
        if self.name:
            return self.name
        cleaned = re.sub(r"[^A-Za-z0-9_.-]", "-", self.host).strip("-.") or "ssh-node"
        return cleaned if _NAME_RE.fullmatch(cleaned) else f"n{cleaned}"

    def join_args(self) -> list[str]:
        """The ``join`` flags of this node (the installer passes them on)."""
        args: list[str] = []
        if self.workers is not None:
            args += ["--workers", str(self.workers)]
        if self.evaluators is not None:
            args += ["--evaluators", str(self.evaluators)]
        args += ["--name", self.display_name]
        if self.tags:
            args += ["--tags", ",".join(self.tags)]
        return args

    def to_json(self) -> dict[str, Any]:
        return {"target": self.target, "workers": self.workers, "evaluators": self.evaluators, "name": self.name,
                "tags": list(self.tags), "ssh_opts": list(self.ssh_opts), "ssh_id": self.ssh_id,
                "node_id": self.node_id}

    @classmethod
    def from_json(cls, data: dict[str, Any]) -> SshNodeSpec:
        return cls(target=data["target"], workers=data.get("workers"), evaluators=data.get("evaluators"),
                   name=data.get("name"), tags=tuple(data.get("tags", ())), ssh_opts=tuple(data.get("ssh_opts", ())),
                   ssh_id=data.get("ssh_id", ""), node_id=data.get("node_id"))


def new_ssh_id() -> str:
    return secrets.token_hex(16)


def ssh_command(spec: SshNodeSpec, *, forward_host: str, forward_port: int, ssh: str = "ssh") -> list[str]:
    """The ``ssh`` argv of a link: reverse-forward only the hub port, run ``sh -s -- <join flags>`` remotely
    (the remote login shell parses the command string, so every argument is quoted)."""
    if not 0 < int(forward_port) < 65536:
        raise ValueError(f"forward port {forward_port} out of range")
    host = f"[{forward_host}]" if ":" in forward_host else forward_host
    argv = [ssh, "-T", "-o", "BatchMode=yes", "-o", "ExitOnForwardFailure=yes", "-o", "LogLevel=INFO",
            "-o", "ServerAliveInterval=10", "-o", "ServerAliveCountMax=3"]
    for opt in spec.ssh_opts:
        argv += ["-o", opt]
    # The remote command starts with "sh", never with "-", so ssh cannot read it as an option.
    argv += ["-R", f"0:{host}:{int(forward_port)}", spec.target,
             " ".join(["sh", "-s", "--", *(shlex.quote(a) for a in spec.join_args())])]
    return argv


def stdin_preamble(*, token: str, ssh_id: str) -> bytes:
    """Shell lines before the installer: the token, the link id and the session flag as exported variables
    (stdin is encrypted by ssh; nothing secret appears in the remote process list)."""
    lines = [f"{TOKEN_ENV}={shlex.quote(token)}; export {TOKEN_ENV}",
             f"{SSH_ID_ENV}={shlex.quote(ssh_id)}; export {SSH_ID_ENV}",
             f"{SSH_SESSION_ENV}=1; export {SSH_SESSION_ENV}"]
    return ("\n".join(lines) + "\n").encode()


def parse_allocated_port(line: bytes) -> int | None:
    """The remote port of ``Allocated port N for remote forward to host:port`` (ssh at LogLevel INFO), or None."""
    match = _ALLOCATED_RE.search(line)
    if match is None:
        return None
    port = int(match.group(1))
    return port if 0 < port < 65536 else None


class _ArgError(ValueError):
    pass


class _Parser(argparse.ArgumentParser):
    def error(self, message: str) -> None:  # noqa: D401 - argparse hook
        raise _ArgError(message)


def _node_parser() -> _Parser:
    parser = _Parser(prog="nodes add", add_help=False, allow_abbrev=False)
    parser.add_argument("target")
    parser.add_argument("--workers", type=int)
    parser.add_argument("--evaluators", type=int)
    parser.add_argument("--name")
    parser.add_argument("--tags", default="")
    parser.add_argument("--ssh-opt", action="append", default=[], dest="ssh_opts")
    return parser


def parse_node_args(argv: Sequence[str]) -> SshNodeSpec:
    """``USER@HOST [--workers N] [--evaluators N] [--name NAME] [--tags a,b] [--ssh-opt OPT ...]``; ValueError."""
    try:
        ns = _node_parser().parse_args(list(argv))
    except _ArgError as e:
        raise ValueError(str(e)) from None
    tags = tuple(t for t in (s.strip() for s in ns.tags.split(",")) if t)
    return SshNodeSpec(target=ns.target, workers=ns.workers, evaluators=ns.evaluators, name=ns.name, tags=tags,
                       ssh_opts=tuple(ns.ssh_opts))


def parse_hosts_file(path: Path) -> list[SshNodeSpec]:
    """``--nodes hosts.txt``: one ``user@host [flags]`` per line (``#`` comments, blank lines skipped). A bad line
    is a ValueError naming the file and line; a target listed twice keeps the last line."""
    specs: dict[str, SshNodeSpec] = {}
    for number, raw in enumerate(Path(path).read_text().splitlines(), start=1):
        line = raw.split("#", 1)[0].strip()
        if not line:
            continue
        try:
            spec = parse_node_args(shlex.split(line))
        except ValueError as e:
            raise ValueError(f"{path}:{number}: {e}") from None
        specs.pop(spec.target, None)
        specs[spec.target] = spec
    return list(specs.values())


class SshNodeBook:
    """``ssh_nodes.json``: ``{"version": 1, "nodes": [SshNodeSpec.to_json(), ...]}``, one record per target, in
    the order added; written atomically with mode 0600. Main loop only."""

    def __init__(self, path: Path) -> None:
        self._path = Path(path)
        self._specs: dict[str, SshNodeSpec] = {}
        if self._path.is_file():
            try:
                data = json.loads(self._path.read_text())
                if data.get("version") != SSH_NODES_VERSION:
                    raise ValueError(f"version {data.get('version')!r}, expected {SSH_NODES_VERSION}")
                for item in data["nodes"]:
                    spec = SshNodeSpec.from_json(item)
                    self._specs[spec.target] = spec
            except (OSError, ValueError, KeyError, TypeError) as e:
                raise ValueError(f"cannot read {self._path} ({type(e).__name__}: {e}); fix or move it away "
                                 f"(the remembered SSH nodes are then forgotten)") from e

    @property
    def path(self) -> Path:
        return self._path

    def specs(self) -> list[SshNodeSpec]:
        return list(self._specs.values())

    def put(self, spec: SshNodeSpec) -> SshNodeSpec:
        """Remember ``spec`` (a new target gets a new ssh id; an existing one keeps its ssh id and node id and takes
        the new flags). Returns the stored record."""
        old = self._specs.get(spec.target)
        stored = replace(spec, ssh_id=old.ssh_id if old else (spec.ssh_id or new_ssh_id()),
                         node_id=old.node_id if old else spec.node_id)
        self._specs[spec.target] = stored
        self._save()
        return stored

    def set_node_id(self, ssh_id: str, node_id: str) -> SshNodeSpec | None:
        for target, spec in self._specs.items():
            if spec.ssh_id == ssh_id:
                if spec.node_id != node_id:
                    self._specs[target] = replace(spec, node_id=node_id)
                    self._save()
                return self._specs[target]
        return None

    def find(self, *, target: str | None = None, ssh_id: str | None = None,
             node_id: str | None = None) -> SshNodeSpec | None:
        for spec in self._specs.values():
            if (target is not None and spec.target == target) or (ssh_id is not None and spec.ssh_id == ssh_id) \
                    or (node_id is not None and spec.node_id == node_id):
                return spec
        return None

    def remove(self, target: str) -> SshNodeSpec | None:
        spec = self._specs.pop(target, None)
        if spec is not None:
            self._save()
        return spec

    def _save(self) -> None:
        self._path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self._path.with_name(f".{self._path.name}.tmp-{os.getpid()}")
        data = json.dumps({"version": SSH_NODES_VERSION, "nodes": [s.to_json() for s in self._specs.values()]},
                          indent=1) + "\n"
        fd = os.open(tmp, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
        try:
            os.write(fd, data.encode())
            os.fsync(fd)
        finally:
            os.close(fd)
        os.replace(tmp, self._path)


@dataclass(frozen=True)
class SshEvent:
    """A link's news for the hub main loop (posted from the reader threads)."""

    ssh_id: str
    kind: Literal["up", "exited"]
    remote_port: int | None = None
    message: str = ""


def _ssh_preexec() -> None:  # pragma: no cover - runs in the forked child
    if sys.platform.startswith("linux"):
        try:
            import ctypes

            ctypes.CDLL(None, use_errno=True).prctl(1, int(signal.SIGTERM), 0, 0, 0)   # PR_SET_PDEATHSIG
        except (OSError, AttributeError):
            pass


@dataclass
class _Run:
    """One ssh process of a link."""

    proc: Any
    started: float
    threads: list[threading.Thread] = field(default_factory=list)
    up_at: float | None = None
    remote_port: int | None = None


class SshLink:
    """One SSH node's ssh process with restarts (module docstring). ``payload(remote_port)`` is the stdin
    payload (preamble + installer script for ``127.0.0.1:<remote_port>``)."""

    def __init__(self, spec: SshNodeSpec, *, payload: Callable[[int], bytes], forward: tuple[str, int],
                 log_path: Path, on_event: Callable[[SshEvent], None], ssh: str = "ssh",
                 popen: Callable[..., Any] = subprocess.Popen) -> None:
        self.spec = spec
        self._payload = payload
        self._forward = forward
        self._log_path = Path(log_path)
        self._on_event = on_event
        self._ssh = ssh
        self._popen = popen
        self._run: _Run | None = None
        self._state: LinkState = "stopped"
        self._backoff = 0.0
        self._next_attempt: float | None = None
        self._errors: deque[str] = deque(maxlen=SSH_ERROR_LINES)
        self._last_error = ""
        self.starts = 0

    # -- read-only views (main loop) -------------------------------------------------------------------------

    @property
    def state(self) -> LinkState:
        return self._state

    @property
    def remote_port(self) -> int | None:
        run = self._run
        return None if run is None else run.remote_port

    @property
    def last_error(self) -> str:
        return self._last_error

    def describe(self, now: float) -> dict[str, Any]:
        wait = None if self._next_attempt is None else max(0.0, self._next_attempt - now)
        return {"target": self.spec.target, "name": self.spec.display_name, "state": self._state,
                "remote_port": self.remote_port, "starts": self.starts, "retry_in_sec": wait,
                "last_error": self._last_error, "node_id": self.spec.node_id}

    # -- main loop -----------------------------------------------------------------------------------------

    def start(self, now: float) -> None:
        """Start ssh now (state ``starting``)."""
        if self._run is not None:
            return
        argv = ssh_command(self.spec, forward_host=self._forward[0], forward_port=self._forward[1], ssh=self._ssh)
        self._log_path.parent.mkdir(parents=True, exist_ok=True)
        log = open(self._log_path, "ab")  # noqa: SIM115 - owned by the reader threads, closed by the last one
        log.write(f"--- ssh start {self.starts + 1}: {shlex.join(argv)}\n".encode())
        log.flush()
        self._errors.clear()
        try:
            proc = self._popen(argv, stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                               start_new_session=True, preexec_fn=_ssh_preexec, close_fds=True)
        except OSError as e:
            log.close()
            self._last_error = f"cannot start {self._ssh!r}: {e}"
            self._schedule(now, failed_fast=True)
            return
        self.starts += 1
        run = _Run(proc=proc, started=now)
        self._run = run
        self._state = "starting"
        self._next_attempt = None
        closing = _Closer(log, 2)
        run.threads = [
            threading.Thread(target=self._read_stderr, args=(run, closing), name=f"ssh-err-{self.spec.ssh_id[:8]}",
                             daemon=True),
            threading.Thread(target=self._read_stdout, args=(run, closing), name=f"ssh-out-{self.spec.ssh_id[:8]}",
                             daemon=True),
        ]
        for thread in list(run.threads):
            thread.start()

    def poll(self, now: float) -> None:
        """Main loop pass: a finished ssh goes to backoff, a port that never came kills ssh, a due retry starts."""
        run = self._run
        if run is not None:
            code = run.proc.poll()
            if code is None:
                if run.remote_port is None and now - run.started >= SSH_PORT_TIMEOUT_SEC:
                    self._errors.append(f"no 'Allocated port' line within {SSH_PORT_TIMEOUT_SEC:g} s")
                    self._kill(run)
                elif run.remote_port is not None and self._state == "starting":
                    run.up_at = now
                    self._state = "up"
                return
            self._reap(run)
            tail = "; ".join(list(self._errors)[-3:])
            self._last_error = f"ssh exited with code {code}" + (f": {tail}" if tail else "")
            if self._state != "stopped":
                stable = run.up_at is not None and now - run.up_at >= SSH_STABLE_SEC
                self._schedule(now, failed_fast=not stable)
            self._on_event(SshEvent(self.spec.ssh_id, "exited", None, self._last_error))
            return
        if self._state == "backoff" and self._next_attempt is not None and now >= self._next_attempt:
            self.start(now)

    def finish(self) -> None:
        """No more restarts, but let the running ssh end by itself (``nodes remove``: the remote node stops after its
        matches and closes the session); ``stop`` it if it does not."""
        self._state = "stopped"
        self._next_attempt = None

    def stop(self) -> None:
        """No more restarts; terminate ssh (kill after ``SSH_STOP_GRACE_SEC``)."""
        self._state = "stopped"
        self._next_attempt = None
        run = self._run
        if run is None:
            return
        self._kill(run)
        try:
            run.proc.wait(timeout=SSH_STOP_GRACE_SEC)
        except subprocess.TimeoutExpired:
            run.proc.kill()
            run.proc.wait(timeout=SSH_STOP_GRACE_SEC)
        self._reap(run)

    def _reap(self, run: _Run) -> None:
        """After the exit: join the reader / writer threads, close the pipes."""
        for thread in list(run.threads):
            thread.join(timeout=1.0)
        for pipe in (run.proc.stdin, run.proc.stdout, run.proc.stderr):
            try:
                if pipe is not None:
                    pipe.close()
            except OSError:
                pass
        self._run = None

    def _schedule(self, now: float, *, failed_fast: bool) -> None:
        self._backoff = (min(SSH_BACKOFF_MAX_SEC, max(SSH_BACKOFF_MIN_SEC, self._backoff * 2)) if failed_fast
                         else SSH_BACKOFF_MIN_SEC)
        self._state = "backoff"
        self._next_attempt = now + self._backoff

    @staticmethod
    def _kill(run: _Run) -> None:
        try:
            if run.proc.stdin is not None:
                run.proc.stdin.close()
        except OSError:
            pass
        try:
            run.proc.terminate()
        except OSError:
            pass

    # -- reader threads ------------------------------------------------------------------------------------

    def _read_stderr(self, run: _Run, closing: _Closer) -> None:
        try:
            for line in iter(run.proc.stderr.readline, b""):
                closing.write(line)
                text = line.decode(errors="replace").strip()
                if text:
                    self._errors.append(text)
                if run.remote_port is None:
                    port = parse_allocated_port(line)
                    if port is not None:
                        run.remote_port = port
                        # A writer thread: a slow remote must not stop this thread from draining stderr.
                        writer = threading.Thread(target=self._send_payload, args=(run, port, closing),
                                                  name=f"ssh-in-{self.spec.ssh_id[:8]}", daemon=True)
                        run.threads.append(writer)
                        writer.start()
        finally:
            closing.done()

    def _send_payload(self, run: _Run, port: int, closing: _Closer) -> None:
        try:
            data = self._payload(port)
            run.proc.stdin.write(data)
            run.proc.stdin.flush()             # stdin stays open: the remote node stops at its EOF
        except (OSError, ValueError) as e:     # ssh died meanwhile; poll() sees the exit
            closing.write(f"--- writing the installer to ssh failed: {e}\n".encode())
            return
        self._on_event(SshEvent(self.spec.ssh_id, "up", port, ""))

    def _read_stdout(self, run: _Run, closing: _Closer) -> None:
        try:
            for line in iter(run.proc.stdout.readline, b""):
                closing.write(line)
        finally:
            closing.done()


class _Closer:
    """A log file shared by a link's two reader threads; closed by the last one."""

    def __init__(self, file: Any, users: int) -> None:
        self._file = file
        self._users = users
        self._lock = threading.Lock()

    def write(self, data: bytes) -> None:
        with self._lock:
            if not self._file.closed:
                self._file.write(data)
                self._file.flush()

    def done(self) -> None:
        with self._lock:
            self._users -= 1
            if self._users == 0:
                self._file.close()


class SshLinks:
    """Every link of the hub, by ssh id (main loop only)."""

    def __init__(self, *, payload_for: Callable[[SshNodeSpec], Callable[[int], bytes]], forward: tuple[str, int],
                 log_dir: Path, on_event: Callable[[SshEvent], None], ssh: str = "ssh",
                 clock: Callable[[], float] = time.monotonic) -> None:
        self._payload_for = payload_for
        self._forward = forward
        self._log_dir = Path(log_dir)
        self._on_event = on_event
        self._ssh = ssh
        self._clock = clock
        self._links: dict[str, SshLink] = {}

    def __contains__(self, ssh_id: str) -> bool:
        return ssh_id in self._links

    def get(self, ssh_id: str) -> SshLink | None:
        return self._links.get(ssh_id)

    def start(self, spec: SshNodeSpec) -> SshLink:
        """Start a link for ``spec`` (an existing link of the same ssh id is stopped first: new flags)."""
        old = self._links.pop(spec.ssh_id, None)
        if old is not None:
            old.stop()
        link = SshLink(spec, payload=self._payload_for(spec), forward=self._forward,
                       log_path=self._log_dir / f"ssh-{spec.display_name}.log", on_event=self._on_event,
                       ssh=self._ssh)
        self._links[spec.ssh_id] = link
        link.start(self._clock())
        return link

    def retire(self, ssh_id: str) -> None:
        link = self._links.pop(ssh_id, None)
        if link is not None:
            link.stop()

    def poll(self) -> None:
        now = self._clock()
        for link in list(self._links.values()):
            link.poll(now)

    def describe(self) -> list[dict[str, Any]]:
        now = self._clock()
        return [link.describe(now) for link in self._links.values()]

    def stop_all(self) -> None:
        for ssh_id in list(self._links):
            self.retire(ssh_id)
```

Notes for the implementer:
- `SshLink.start` / `poll` / `stop` run on the hub main loop thread only: `PR_SET_PDEATHSIG` is delivered when the *thread* that forked ssh exits, and the main loop thread lives as long as the hub. `start_new_session=True` keeps the terminal's Ctrl+C from killing ssh before the distributed stop finished (the remote learner's final snapshot travels through the tunnel); the hub stops the links itself (Step 7).
- The payload is written by a separate thread: a slow remote must not stop the stderr reader (a full stderr pipe would block ssh, which would stop reading stdin).
- `subprocess.Popen(preexec_fn=...)` is safe here although the hub runs threads: the function only calls `prctl` through ctypes (no locks, no allocation by Python code that other threads hold).

```python
def _wait(job, timeout=60.0):
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        result = job.poll()
        if result is not None:
            return result
        time.sleep(0.05)
    raise AssertionError("job did not finish")
```

```python
        return {"id": self.agent_id, "entry": copy.deepcopy(self.entry), "status": self.status, "origin": self.origin,
                "start_env_steps": int(self.start_env_steps), "frozen_version": self.frozen_version}

    @classmethod
    def from_json(cls, data: Mapping[str, Any]) -> AgentRecord:
        status = data["status"]
        if status not in ("active", "frozen", "removed"):
            raise ValueError(f"agent {data.get('id')!r}: unknown status {status!r}")
        frozen = data.get("frozen_version")
        return cls(agent_id=str(data["id"]), entry=dict(data["entry"]), status=status,
                   origin=data.get("origin", "config"), start_env_steps=int(data.get("start_env_steps", 0)),
                   frozen_version=None if frozen is None else int(frozen))


def _entry_of(config: ColosseumConfig, agent_id: str) -> dict[str, Any]:
    entry = config.agents.get(agent_id)
    if entry is None:                  # the implicit agent_0
        return {"kind": "trainable"}
    dump = entry.model_dump(mode="json", by_alias=True)
    return {k: v for k, v in dump.items() if v is not None}     # omitted fields stay omitted (defaults)


def add_anchor(value: Any, name: str, weight: float, fixed_before: Sequence[str]) -> Any:
    """``matchmaking.anchors`` with ``name`` added at ``weight``: ``null`` (every fixed agent, weight 1) stays null for
    weight 1, else becomes a mapping of ``fixed_before`` at 1 plus ``name``; a list gains ``name`` (or becomes a mapping
    for a weight other than 1); a mapping gains the key."""
    weight = float(weight)
    if value is None:
        return None if weight == 1.0 else {**{a: 1.0 for a in fixed_before if a != name}, name: weight}
    if isinstance(value, list):
        if weight == 1.0:
            return [*[a for a in value if a != name], name]
        return {**{a: 1.0 for a in value if a != name}, name: weight}
    return {**{k: v for k, v in value.items() if k != name}, name: weight}


def drop_anchor(value: Any, name: str) -> Any:
    """``matchmaking.anchors`` without ``name`` (``null`` stays null: a removed agent leaves the fixed set)."""
    if value is None:
        return None
    if isinstance(value, list):
        return [a for a in value if a != name]
    return {k: v for k, v in value.items() if k != name}


def parse_fragment(text: str, *, agent_id: str) -> tuple[dict[str, Any], float | None]:
    """An ``agents add`` fragment: the YAML ``agents.<id>`` entry (``kind`` defaults to trainable), plus the optional
    ``anchor_weight`` (> 0; scripted / frozen agents only: the new agent becomes an anchor of every active trainable
    agent with this weight). Returns ``(entry, anchor_weight)``; ConfigError for malformed input."""
    check_agent_id(agent_id)
    try:
        data = yaml.safe_load(text)
    except yaml.YAMLError as e:
        raise ConfigError(f"agents add {agent_id}: the fragment is not valid YAML: {e}") from e
    if data is None:
        data = {}
    if not isinstance(data, dict):
        raise ConfigError(f"agents add {agent_id}: the fragment must be a mapping (the agents.{agent_id} entry), "
                          f"got {type(data).__name__}")
    if "agents" in data or "id" in data:
        raise ConfigError(f"agents add {agent_id}: write the entry itself (kind, class / path / networks, ...), not "
                          f"an agents section; the id comes from --id")
    entry = {k: v for k, v in data.items() if k not in FRAGMENT_KEYS}
    entry.setdefault("kind", "trainable")
    weight = data.get("anchor_weight")
    if weight is not None:
        if isinstance(weight, bool) or not isinstance(weight, int | float) or not weight > 0:
            raise ConfigError(f"agents add {agent_id}: anchor_weight must be a number > 0, got {weight!r}")
        if entry["kind"] == "trainable":
            raise ConfigError(f"agents add {agent_id}: anchor_weight is for scripted / frozen agents; a trainable "
                              f"agent meets others through opponents.rivals")
        weight = float(weight)
    return entry, weight


@dataclass(frozen=True)
class AgentSet:
    base: ColosseumConfig
    records: tuple[AgentRecord, ...]
    version: int = 0
    anchors: tuple[bool, Any] = (False, None)          # (overridden, global matchmaking.anchors)
    history: tuple[dict[str, Any], ...] = field(default=())

    # -- construction ------------------------------------------------------------------------------------------

    @classmethod
    def from_config(cls, config: ColosseumConfig) -> AgentSet:
        """Every agent of ``config`` active, start 0 (a run's first start, or a run dir without agents_state.json)."""
        records = tuple(AgentRecord(aid, _entry_of(config, aid)) for aid in config.agent_ids())
        return cls(base=config, records=records)

    @classmethod
    def from_state(cls, base: ColosseumConfig, state: Mapping[str, Any]) -> AgentSet:
        """An in-place resume without ``-c`` (spec 5.4): ``base`` = the saved config, the agents and the anchor
        override from ``state``. ValueError for a malformed state."""
        if state.get("version") != AGENTS_STATE_VERSION:
            raise ValueError(f"agents_state version {state.get('version')!r}, expected {AGENTS_STATE_VERSION}")
        records = tuple(AgentRecord.from_json(r) for r in state["agents"])
        ids = [r.agent_id for r in records]
        if len(set(ids)) != len(ids):
            raise ValueError(f"agents_state lists an agent twice: {ids}")
        anchors = state.get("anchors", {"overridden": False, "value": None})
        out = cls(base=base, records=records, version=int(state.get("agents_version", 0)),
                  anchors=(bool(anchors["overridden"]), anchors.get("value")),
                  history=tuple(state.get("history", ())))
        out.config()                       # the entries must still make a valid config
        return out

    @classmethod
    def reconcile(cls, config: ColosseumConfig, state: Mapping[str, Any] | None, *,
                  env_steps: int) -> tuple[AgentSet, list[str]]:
        """An in-place resume with ``-c`` (spec 5.4): the new config is the agent set. Agents of the saved state that
        the config still has keep their start point; new ones start at ``env_steps``; saved agents the config no
        longer has are kept as ``removed``; the anchor override is dropped. Returns the set and WARNING lines (a
        frozen or removed agent active again, a dropped anchor override)."""
        warnings: list[str] = []
        old = {r.agent_id: r for r in (AgentRecord.from_json(x) for x in state["agents"])} if state else {}
        records = []
        for aid in config.agent_ids():
            prev = old.get(aid)
            if prev is not None and prev.status != "active":
                warnings.append(f"agent {aid!r} was {prev.status} and is active again (the -c config lists it)")
            start = prev.start_env_steps if prev is not None else (0 if not state else int(env_steps))
            origin = prev.origin if prev is not None else ("config" if not state else "added")
            records.append(AgentRecord(aid, _entry_of(config, aid), "active", origin, start))
        for aid, prev in old.items():
            if aid not in config.agent_ids():
                records.append(replace(prev, status="removed"))
        if state and state.get("anchors", {}).get("overridden"):
            warnings.append("the matchmaking.anchors changes of agents add / freeze / remove are dropped (the -c "
                            "config sets the anchors)")
        version = int(state.get("agents_version", 0)) + 1 if state else 0
        history = tuple(state.get("history", ())) if state else ()
        return cls(base=config, records=tuple(records), version=version, history=history), warnings

    # -- views -------------------------------------------------------------------------------------------------

    def get(self, agent_id: str) -> AgentRecord | None:
        return next((r for r in self.records if r.agent_id == agent_id), None)

    def seated(self) -> list[AgentRecord]:
        return [r for r in self.records if r.status != "removed"]

    def active_trainable(self) -> list[str]:
        return [r.agent_id for r in self.records if r.status == "active" and r.kind == "trainable"]

    def frozen_versions(self) -> dict[str, int]:
        return {r.agent_id: int(r.frozen_version) for r in self.records
                if r.status == "frozen" and r.frozen_version is not None}

    def removed(self) -> list[str]:
        return [r.agent_id for r in self.records if r.status == "removed"]

    def config(self) -> ColosseumConfig:
        """The effective config (module docstring)."""
        data = self.base.model_dump(mode="json", by_alias=True)
        data["agents"] = {r.agent_id: copy.deepcopy(r.entry) for r in self.seated()}
        overridden, value = self.anchors
        if overridden:
            data["matchmaking"]["anchors"] = copy.deepcopy(value)
        try:
            return ColosseumConfig.model_validate(data)
        except Exception as e:  # noqa: BLE001 - pydantic ValidationError and friends
            raise ConfigError(f"the agent set does not make a valid config: {e}") from e

    def membership(self) -> Membership:
        seated = self.seated()
        return Membership(kinds={r.agent_id: r.seated_kind for r in seated}, frozen_versions=self.frozen_versions(),
                          start_env_steps={r.agent_id: r.start_env_steps for r in seated if r.kind == "trainable"},
                          historical=tuple(self.removed()))

    # -- operations --------------------------------------------------------------------------------------------

    def _check_static_refresh(self, op: str) -> None:
        if self.base.rollout.match_refresh_interval_sec <= 0:
            raise ConfigError(f"agents {op}: rollout.match_refresh_interval_sec is 0, so lineups never change during "
                              f"this run; restart the hub with --resume and the new agent set in the config")

    def _anchor_edits(self, edit: Any) -> tuple[tuple[bool, Any], dict[str, dict[str, Any]]]:
        """Apply ``edit(value)`` to the global ``matchmaking.anchors`` and to every active trainable agent's own
        ``matchmaking.anchors`` override; returns the new global override and the changed entries."""
        overridden, value = self.anchors
        current = value if overridden else copy.deepcopy(self.base.matchmaking.anchors)
        new_global = edit(current)
        changed: dict[str, dict[str, Any]] = {}
        for r in self.records:
            mm = r.entry.get("matchmaking") or {}
            if r.status == "active" and r.kind == "trainable" and "anchors" in mm:
                entry = copy.deepcopy(r.entry)
                entry["matchmaking"]["anchors"] = edit(mm["anchors"])
                changed[r.agent_id] = entry
        anchors = (overridden or new_global != current, new_global)
        return anchors, changed

    def _with(self, records: Sequence[AgentRecord], *, anchors: tuple[bool, Any], op: str, agent_id: str,
              env_steps: int, detail: Mapping[str, Any]) -> AgentSet:
        item = {"agents_version": self.version + 1, "env_steps": int(env_steps), "op": op, "agent": agent_id,
                "detail": dict(detail)}
        out = replace(self, records=tuple(records), version=self.version + 1, anchors=anchors,
                      history=(*self.history, item)[-HISTORY_LIMIT:])
        out.config()                       # entries still make a valid config (pydantic level)
        return out

    def with_added(self, agent_id: str, entry: Mapping[str, Any], *, anchor_weight: float | None,
                   env_steps: int) -> AgentSet:
        """``agents add``: a new agent (any kind), start at ``env_steps``."""
        self._check_static_refresh("add")
        check_agent_id(agent_id)
        existing = self.get(agent_id)
        if existing is not None:
            hint = ("; removed agents keep their id (their history stays): pick another id" if existing.status ==
                    "removed" else "")
            raise ConfigError(f"agents add: agent {agent_id!r} already exists ({existing.status}){hint}")
        if env_steps >= self.base.training.total_timesteps:
            raise ConfigError(f"agents add: the run is at its budget ({env_steps} of "
                              f"{self.base.training.total_timesteps} env steps); resume with a larger "
                              f"--set training.total_timesteps first")
        entry = dict(copy.deepcopy(dict(entry)))
        entry.setdefault("kind", "trainable")
        record = AgentRecord(agent_id, entry, "active", "added", int(env_steps))
        records = [*self.records, record]
        anchors = self.anchors
        if anchor_weight is not None:
            if entry["kind"] == "trainable":
                raise ConfigError(f"agents add {agent_id}: anchor_weight is for scripted / frozen agents")
            fixed_before = [r.agent_id for r in self.seated() if r.seated_kind != "trainable"]
            anchors, changed = self._anchor_edits(lambda v: add_anchor(v, agent_id, anchor_weight, fixed_before))
            records = [replace(r, entry=changed[r.agent_id]) if r.agent_id in changed else r for r in records]
        return self._with(records, anchors=anchors, op="add", agent_id=agent_id, env_steps=env_steps,
                          detail={"kind": entry["kind"], "anchor_weight": anchor_weight})

    def _require_other_trainable(self, op: str, agent_id: str) -> None:
        if self.active_trainable() == [agent_id]:
            raise ConfigError(f"agents {op}: {agent_id!r} is the last active trainable agent; add another trainable "
                              f"agent first, or stop the run (Ctrl+C on the hub)")

    def with_frozen(self, agent_id: str, *, version: int, anchor_weight: float | None, env_steps: int) -> AgentSet:
        """``agents freeze``: an active trainable agent becomes a fixed player of its snapshot ``ckpt_v<version>``."""
        self._check_static_refresh("freeze")
        record = self.get(agent_id)
        if record is None or record.status != "active" or record.kind != "trainable":
            what = "unknown" if record is None else f"{record.status} {record.kind}"
            raise ConfigError(f"agents freeze: {agent_id!r} is not an active trainable agent ({what})")
        self._require_other_trainable("freeze", agent_id)
        frozen = replace(record, status="frozen", frozen_version=int(version))
        records = [frozen if r.agent_id == agent_id else r for r in self.records]
        anchors = self.anchors
        if anchor_weight is not None:
            if not anchor_weight > 0:
                raise ConfigError(f"agents freeze: --anchor-weight must be > 0, got {anchor_weight}")
            fixed_before = [r.agent_id for r in self.seated() if r.seated_kind != "trainable"]
            tmp = replace(self, records=tuple(records))
            anchors, changed = tmp._anchor_edits(lambda v: add_anchor(v, agent_id, anchor_weight, fixed_before))
            records = [replace(r, entry=changed[r.agent_id]) if r.agent_id in changed else r for r in records]
        return self._with(records, anchors=anchors, op="freeze", agent_id=agent_id, env_steps=env_steps,
                          detail={"version": int(version), "anchor_weight": anchor_weight})

    def with_removed(self, agent_id: str, *, env_steps: int) -> AgentSet:
        """``agents remove``: never seated again; its name leaves every anchors list."""
        self._check_static_refresh("remove")
        record = self.get(agent_id)
        if record is None or record.status == "removed":
            raise ConfigError(f"agents remove: {agent_id!r} is not an agent of this run"
                              + ("" if record is None else " any more (already removed)"))
        if record.status == "active" and record.kind == "trainable":
            self._require_other_trainable("remove", agent_id)
        records = [replace(r, status="removed") if r.agent_id == agent_id else r for r in self.records]
        tmp = replace(self, records=tuple(records))
        anchors, changed = tmp._anchor_edits(lambda v: drop_anchor(v, agent_id))
        records = [replace(r, entry=changed[r.agent_id]) if r.agent_id in changed else r for r in records]
        return self._with(records, anchors=anchors, op="remove", agent_id=agent_id, env_steps=env_steps,
                          detail={"was": record.status})

    # -- persistence -------------------------------------------------------------------------------------------

    def state(self, run_id: str | None) -> dict[str, Any]:
        overridden, value = self.anchors
        return {"version": AGENTS_STATE_VERSION, "run_id": run_id, "agents_version": self.version,
                "anchors": {"overridden": overridden, "value": copy.deepcopy(value)},
                "agents": [r.to_json() for r in self.records], "history": [dict(h) for h in self.history]}
```

```python
"""Background jobs of the hub (SP5 T8.2 / T8.3): checks that import user code and may take seconds run outside the
main loop, which only polls them (spec principle: the main loop never blocks).

``JsonJob`` runs ``argv`` as a child process (``subprocess``; its own ``PYTHONPATH`` and cwd, so a check can import
another code bundle) and reads ONE JSON object from the last non-empty line of its stdout; stderr goes to a log
file. ``ThreadJob`` runs a callable in a daemon thread (tests and cheap checks; same ``poll`` contract).
``poll()`` returns None while running, else a ``JobResult``; a job past its timeout is killed and fails with
``timeout``.
"""

from __future__ import annotations

import json
import os
import subprocess
import threading
import time
from collections.abc import Callable, Mapping, Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Any


@dataclass(frozen=True)
class JobResult:
    ok: bool
    value: Any = None          # the parsed JSON object (JsonJob) or the callable's return value (ThreadJob)
    error: str = ""            # "timeout", "exit code N: <stderr tail>", "bad output: ...", or the exception


class JsonJob:
    def __init__(self, argv: Sequence[str], *, timeout_sec: float, log_path: Path, cwd: str | Path | None = None,
                 env: Mapping[str, str] | None = None, clock: Callable[[], float] = time.monotonic) -> None:
        self._clock = clock
        self._deadline = clock() + float(timeout_sec)
        self._log_path = Path(log_path)
        self._log_path.parent.mkdir(parents=True, exist_ok=True)
        self._log = open(self._log_path, "ab")  # noqa: SIM115 - closed in _finish
        self._out = bytearray()
        self._proc = subprocess.Popen(list(argv), stdout=subprocess.PIPE, stderr=self._log, stdin=subprocess.DEVNULL,
                                      cwd=None if cwd is None else str(cwd),
                                      env=None if env is None else dict(env), close_fds=True)
        self._reader = threading.Thread(target=self._read, name="hub-job-out", daemon=True)
        self._reader.start()
        self._result: JobResult | None = None

    def _read(self) -> None:
        assert self._proc.stdout is not None
        for chunk in iter(lambda: self._proc.stdout.read1(65536), b""):
            self._out += chunk

    def poll(self) -> JobResult | None:
        if self._result is not None:
            return self._result
        code = self._proc.poll()
        if code is None:
            if self._clock() < self._deadline:
                return None
            self._proc.kill()
            self._proc.wait()
            return self._finish(JobResult(False, error="timeout"))
        self._reader.join(timeout=5.0)
        if code != 0:
            return self._finish(JobResult(False, error=f"exit code {code}: {self._stderr_tail()}"))
        lines = [ln for ln in bytes(self._out).decode(errors="replace").splitlines() if ln.strip()]
        try:
            value = json.loads(lines[-1])
            if not isinstance(value, dict):
                raise ValueError(f"expected a JSON object, got {type(value).__name__}")
        except (IndexError, ValueError) as e:
            return self._finish(JobResult(False, error=f"bad output: {e}"))
        return self._finish(JobResult(True, value=value))

    def _stderr_tail(self, limit: int = 2000) -> str:
        self._log.flush()
        try:
            data = self._log_path.read_bytes()[-limit:]
        except OSError:
            return ""
        return data.decode(errors="replace").strip()

    def _finish(self, result: JobResult) -> JobResult:
        self._result = result
        self._reader.join(timeout=5.0)
        if self._proc.stdout is not None:
            self._proc.stdout.close()
        self._log.close()
        return result

    def cancel(self) -> None:
        if self._result is None and self._proc.poll() is None:
            self._proc.kill()
            self._proc.wait()
            self._finish(JobResult(False, error="cancelled"))


class ThreadJob:
    def __init__(self, fn: Callable[[], Any], *, timeout_sec: float,
                 clock: Callable[[], float] = time.monotonic) -> None:
        self._clock = clock
        self._deadline = clock() + float(timeout_sec)
        self._result: JobResult | None = None
        self._done = threading.Event()
        self._value: JobResult | None = None
        self._thread = threading.Thread(target=self._run, args=(fn,), name="hub-job", daemon=True)
        self._thread.start()

    def _run(self, fn: Callable[[], Any]) -> None:
        try:
            self._value = JobResult(True, value=fn())
        except Exception as e:  # noqa: BLE001 - reported to the caller
            self._value = JobResult(False, error=f"{type(e).__name__}: {e}")
        self._done.set()

    def poll(self) -> JobResult | None:
        if self._result is None:
            if self._done.is_set():
                self._result = self._value
            elif self._clock() >= self._deadline:
                self._result = JobResult(False, error="timeout")    # the thread is abandoned (daemon)
        return self._result

    def cancel(self) -> None:
        if self._result is None:
            self._result = JobResult(False, error="cancelled")


def python_env(sys_path: Sequence[str], extra: Mapping[str, str] | None = None) -> dict[str, str]:
    """This process's environment with ``PYTHONPATH`` = ``sys_path`` (the child imports exactly what we import)."""
    env = dict(os.environ)
    env["PYTHONPATH"] = os.pathsep.join(p for p in sys_path if p)
    env.update(extra or {})
    return env
```

`src/colosseum/bootstrap/codecheck.py`:
```python
"""What ``colosseum nodes update-code`` may change (SP5 spec block 6.4), as pure functions over bundle members, plus
the child-process check of a new bundle's game (``python -m colosseum.bootstrap.codecheck CONFIG.json``).

Refused (restart the hub with ``--resume``): a changed ``GameSpec`` (roles, their spaces, layouts) or role signature
of any agent; a changed file of the code the hub itself runs (``hub_members``: every ``colosseum`` module loaded in
the hub process, the protocol packages ``colosseum/{net,node,hub,bootstrap}/`` and ``colosseum/core/types.py``
whether loaded or not, and the module of ``matchmaking.matchmaker_class``); a changed node requirement list.
Allowed otherwise; then workers and evaluators restart, and a learner restarts only when a changed file is the
module defining one of its agent's ``networks`` / ``algorithm`` classes or any file of the ``colosseum`` package
(``--restart-learners``: every learner).

Members are archive names of ``colosseum.bootstrap.bundle`` (``member_for(path)`` maps a source file of the hub's
tree to its member, None outside the bundle).
"""

from __future__ import annotations

import hashlib
import importlib.util
import json
import sys
import tarfile
from collections.abc import Callable, Iterable, Mapping, Sequence
from pathlib import Path
from typing import Any

PROTOCOL_DIRS = ("net", "node", "hub", "bootstrap")
PROTOCOL_FILES = ("core/types.py",)
NETWORK_CLASS_FIELDS = ("encoder_class", "policy_class", "value_class", "critic_encoder_class", "model_class")

MemberFor = Callable[[Path], "str | None"]


def spec_summary(spec: Any, agent_roles: Mapping[str, Sequence[str]]) -> dict[str, Any]:
    """The parts of a game an update must not change: per role its signature, per layout its seats (role, team),
    per trainable agent the signature of its role spec; ``fingerprint`` hashes all of it."""
    from colosseum.core.roles import agent_role_spec, role_signature

    roles = {name: role_signature(role) for name, role in sorted(spec.roles.items())}
    layouts = {name: [[seat.role, int(seat.team)] for seat in seats] for name, seats in sorted(spec.layouts.items())}
    agents = {aid: role_signature(agent_role_spec(spec, list(r))) for aid, r in sorted(agent_roles.items())}
    body = {"roles": roles, "layouts": layouts, "agents": agents}
    fingerprint = hashlib.sha256(json.dumps(body, sort_keys=True).encode()).hexdigest()
    return {**body, "fingerprint": fingerprint}


def spec_differences(old: Mapping[str, Any], new: Mapping[str, Any]) -> list[str]:
    """Human-readable differences of two ``spec_summary`` results ([] when equal)."""
    out = []
    for part, what in (("roles", "role"), ("layouts", "layout"), ("agents", "role signature of agent")):
        a, b = old.get(part, {}), new.get(part, {})
        for key in sorted(set(a) | set(b)):
            if key not in b:
                out.append(f"{what} {key!r} is gone")
            elif key not in a:
                out.append(f"{what} {key!r} is new")
            elif a[key] != b[key]:
                out.append(f"{what} {key!r} changed")
    return out


def bundle_digests(archive: Path) -> dict[str, str]:
    """``{member: sha256 hex}`` of every regular file of a bundle archive."""
    out: dict[str, str] = {}
    with tarfile.open(archive, "r:*") as tar:
        for info in tar:
            if info.isfile():
                fh = tar.extractfile(info)
                assert fh is not None
                out[info.name] = hashlib.sha256(fh.read()).hexdigest()
    return out


def changed_members(old: Mapping[str, str], new: Mapping[str, str]) -> list[str]:
    """Members added, removed or changed between two ``bundle_digests`` results, sorted."""
    return sorted(m for m in set(old) | set(new) if old.get(m) != new.get(m))


def module_member(module: str, member_for: MemberFor) -> str | None:
    """The member of the file that defines ``module`` (imports its parent packages, as the hub already did)."""
    try:
        found = importlib.util.find_spec(module)
    except (ImportError, ValueError):
        return None
    if found is None or not found.origin or found.origin in ("built-in", "frozen"):
        return None
    return member_for(Path(found.origin))


def class_member(class_path: str | None, member_for: MemberFor) -> str | None:
    if not class_path or "." not in class_path:
        return None
    return module_member(class_path.rsplit(".", 1)[0], member_for)


def colosseum_prefix(member_for: MemberFor) -> str:
    """The member prefix of the colosseum package (``member_for`` of its directory) plus ``/``."""
    import colosseum

    prefix = member_for(Path(colosseum.__file__).resolve().parent)
    if prefix is None:
        raise ValueError("the colosseum package is not part of the bundle")
    return prefix.rstrip("/") + "/"


def hub_members(*, loaded_files: Iterable[str | Path], all_members: Iterable[str], member_for: MemberFor,
                matchmaker_class: str | None) -> set[str]:
    """Members of the code the hub runs (module docstring). ``loaded_files``: ``__file__`` of every module loaded in
    the hub process (``loaded_module_files()``); ``all_members``: the members of the old and new bundles."""
    prefix = colosseum_prefix(member_for)
    out: set[str] = set()
    for path in loaded_files:
        member = member_for(Path(path))
        if member is not None and member.startswith(prefix):
            out.add(member)
    for member in all_members:
        rest = member[len(prefix):] if member.startswith(prefix) else None
        if rest is not None and (rest.split("/", 1)[0] in PROTOCOL_DIRS or rest in PROTOCOL_FILES):
            out.add(member)
    custom = class_member(matchmaker_class, member_for)
    if custom is not None:
        out.add(custom)
    return out


def loaded_module_files() -> list[str]:
    """``__file__`` of every module loaded in this process (the hub calls it at update time)."""
    return [f for f in (getattr(m, "__file__", None) for m in list(sys.modules.values())) if f]


def agent_class_members(agent_config: Any, member_for: MemberFor) -> set[str]:
    """Members of the modules defining one trainable agent's network classes, core class and algorithm class."""
    paths = [getattr(agent_config.networks, name, None) for name in NETWORK_CLASS_FIELDS]
    core = getattr(agent_config.networks, "core", None)
    if core is not None:
        paths.append(core.class_path)
    paths.append(getattr(agent_config.algorithm, "algorithm_class", None))
    return {m for m in (class_member(p, member_for) for p in paths if isinstance(p, str)) if m is not None}


def learner_restarts(agent_configs: Mapping[str, Any], changed: Iterable[str], *, member_for: MemberFor,
                     restart_all: bool) -> dict[str, str]:
    """``{agent: reason}`` of the learners an update restarts (module docstring)."""
    changed = set(changed)
    prefix = colosseum_prefix(member_for)
    package = sorted(m for m in changed if m.startswith(prefix))
    out: dict[str, str] = {}
    for aid, cfg in agent_configs.items():
        if restart_all:
            out[aid] = "--restart-learners"
        elif package:
            out[aid] = f"the colosseum package changed ({package[0]}{' ...' if len(package) > 1 else ''})"
        else:
            hit = sorted(agent_class_members(cfg, member_for) & changed)
            if hit:
                out[aid] = f"its model / algorithm module changed ({', '.join(hit)})"
    return out


def update_refusals(*, old_spec: Mapping[str, Any], new_spec: Mapping[str, Any], changed: Iterable[str],
                    hub_code: set[str], old_requirements: str, new_requirements: str) -> list[str]:
    """Why an update is refused ([] = allowed); each line names what changed."""
    reasons = [f"the game changed: {d}" for d in spec_differences(old_spec, new_spec)]
    touched = sorted(set(changed) & hub_code)
    if touched:
        reasons.append(f"code the hub runs changed: {', '.join(touched[:5])}{' ...' if len(touched) > 5 else ''}")
    if old_requirements != new_requirements:
        reasons.append("the node requirements changed (the hub's environment or distributed.requirements)")
    return reasons


def main(argv: Sequence[str] | None = None) -> int:
    """``python -m colosseum.bootstrap.codecheck CONFIG.json`` (run with the new bundle on PYTHONPATH and its project
    dir as cwd): prints one JSON line, ``{"ok": true, "spec": spec_summary}`` or ``{"ok": false, "error": ...}``."""
    args = list(sys.argv[1:] if argv is None else argv)
    if len(args) != 1:
        print("usage: python -m colosseum.bootstrap.codecheck CONFIG.json", file=sys.stderr)
        return 2
    try:
        from colosseum.core.config import ColosseumConfig
        from colosseum.core.registry import env_spec
        from colosseum.core.roles import resolve_agent_roles

        config = ColosseumConfig.model_validate(json.loads(Path(args[0]).read_text()))
        spec = env_spec(config)
        out: dict[str, Any] = {"ok": True, "spec": spec_summary(spec, resolve_agent_roles(config, spec))}
    except Exception as e:  # noqa: BLE001 - reported to the hub
        out = {"ok": False, "error": f"{type(e).__name__}: {e}"}
    sys.stdout.write(json.dumps(out) + "\n")
    sys.stdout.flush()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

`src/colosseum/hub/update.py`:
```python
"""The rolling code update of ``colosseum nodes update-code`` (SP5 spec block 6.4), as a pure state machine on the
hub's clock (main loop only).

Nodes are updated one at a time, in node-number order (nodes that join during the update with the old code hash are
appended). For the current node the hub sends ``Command(update_code, code_hash)``; the node downloads the bundle and
restarts its workers and evaluators at the end of their episodes / blocks with the new code, then reports
``Event(kind="code_updated")`` (or ``code_update_failed`` with a message). Then the hub restarts the node's learners
that need it (``codecheck.learner_restarts``) from a fresh recovery point, one after another; when the last one is
back (its new generation announced a version) the node is done and the next one starts. A node that is lost, fails
or does not answer within ``node_timeout_sec`` is ``failed`` and the update moves on; a learner that does not come
back within ``learner_timeout_sec`` is reported and the update moves on (the learner's own restart rules apply).
While the update runs the hub accepts both code hashes at registration (``accepts``); afterwards only the new one.
"""

from __future__ import annotations

from collections.abc import Mapping, Sequence
from dataclasses import dataclass, field
from typing import Any, Literal

UPDATE_NODE_TIMEOUT_SEC = 900.0       # bundle download + every worker's episode end
UPDATE_LEARNER_TIMEOUT_SEC = 300.0    # recovery point upload + restart + first version

NodeState = Literal["queued", "updating", "learners", "done", "failed"]


@dataclass
class NodeUpdate:
    node: int
    state: NodeState = "queued"
    learners: list[str] = field(default_factory=list)      # still to restart on this node, in order
    restarted: list[str] = field(default_factory=list)
    detail: str = ""
    deadline: float | None = None


@dataclass(frozen=True)
class UpdateAction:
    """What the hub must do now: send ``update_code`` to ``node``, or restart ``learner`` (on ``node``)."""

    kind: Literal["send_update", "restart_learner"]
    node: int
    learner: str | None = None


class RollingUpdate:
    def __init__(self, *, old_hash: str, new_hash: str, nodes: Sequence[int],
                 learners_by_node: Mapping[int, Sequence[str]], restart: Mapping[str, str], now: float,
                 node_timeout_sec: float = UPDATE_NODE_TIMEOUT_SEC,
                 learner_timeout_sec: float = UPDATE_LEARNER_TIMEOUT_SEC) -> None:
        self.old_hash = old_hash
        self.new_hash = new_hash
        self.restart = dict(restart)            # agent -> reason
        self._learners_by_node = {int(n): list(a) for n, a in learners_by_node.items()}
        self._node_timeout = float(node_timeout_sec)
        self._learner_timeout = float(learner_timeout_sec)
        self.nodes: dict[int, NodeUpdate] = {}
        for node in sorted(set(int(n) for n in nodes)):
            self.add_node(node)
        self._current: int | None = None
        self.started = now
        self.log: list[str] = []

    # -- membership -------------------------------------------------------------------------------------------

    def add_node(self, node: int, learners: Sequence[str] | None = None) -> None:
        """A node to update (at the start, or one that joined with the old hash during the update)."""
        if node in self.nodes:
            return
        if learners is not None:
            self._learners_by_node[node] = list(learners)
        todo = [a for a in self._learners_by_node.get(node, []) if a in self.restart]
        self.nodes[node] = NodeUpdate(node=node, learners=todo)

    def accepts(self, code_hash: str) -> bool:
        """Registration check during the update: the old and the new hash; afterwards (``done``) only the new."""
        return code_hash == self.new_hash or (code_hash == self.old_hash and not self.done)

    @property
    def done(self) -> bool:
        return all(u.state in ("done", "failed") for u in self.nodes.values())

    @property
    def current(self) -> int | None:
        return self._current

    # -- progress ---------------------------------------------------------------------------------------------

    def step(self, now: float) -> list[UpdateAction]:
        """Advance: time out the current node or learner, start the next node, or ask for the next learner."""
        actions: list[UpdateAction] = []
        cur = self.nodes.get(self._current) if self._current is not None else None
        if cur is not None and cur.deadline is not None and now >= cur.deadline:
            if cur.state == "updating":
                self._fail(cur, f"no code_updated within {self._node_timeout:g} s")
            elif cur.state == "learners" and cur.learners:
                agent = cur.learners.pop(0)
                self.log.append(f"node {cur.node}: learner {agent!r} did not come back within "
                                f"{self._learner_timeout:g} s; moving on")
                cur.deadline = None
            cur = self.nodes.get(self._current) if self._current is not None else None
        if cur is not None and cur.state == "learners" and cur.deadline is None:
            if cur.learners:
                cur.deadline = now + self._learner_timeout
                actions.append(UpdateAction("restart_learner", cur.node, cur.learners[0]))
            else:
                cur.state = "done"
                self.log.append(f"node {cur.node}: updated")
                self._current = None
                cur = None
        if cur is None:
            nxt = next((u for u in sorted(self.nodes.values(), key=lambda u: u.node) if u.state == "queued"), None)
            if nxt is not None:
                nxt.state = "updating"
                nxt.deadline = now + self._node_timeout
                self._current = nxt.node
                actions.append(UpdateAction("send_update", nxt.node))
        return actions

    def on_node_event(self, node: int, kind: str, message: str, now: float) -> None:
        """``Event(code_updated | code_update_failed)`` from ``node``."""
        u = self.nodes.get(node)
        if u is None or u.state != "updating":
            return
        if kind == "code_updated":
            u.state = "learners"
            u.deadline = None
        else:
            self._fail(u, message or "the node reported a failure")

    def on_learner_back(self, agent: str) -> None:
        """The restarted learner of ``agent`` announced its first version."""
        cur = self.nodes.get(self._current) if self._current is not None else None
        if cur is not None and cur.state == "learners" and cur.learners and cur.learners[0] == agent:
            cur.restarted.append(cur.learners.pop(0))
            cur.deadline = None

    def on_node_lost(self, node: int) -> None:
        u = self.nodes.get(node)
        if u is not None and u.state in ("queued", "updating", "learners"):
            self._fail(u, "lost")

    def _fail(self, u: NodeUpdate, detail: str) -> None:
        u.state = "failed"
        u.detail = detail
        u.deadline = None
        self.log.append(f"node {u.node}: failed ({detail})")
        if self._current == u.node:
            self._current = None

    def progress(self) -> list[dict[str, Any]]:
        return [{"node": u.node, "state": u.state, "learners": list(u.learners), "restarted": list(u.restarted),
                 "detail": u.detail} for u in sorted(self.nodes.values(), key=lambda u: u.node)]
```

```yaml
# Image: the hub runs the full colosseum with your project (configs, env, bots, models), so it is built from
# your repository with the hub target of the node Dockerfile (as deployment/compose.yaml does):
#   docker build -f deployment/Dockerfile.node --target hub -t colosseum-hub:latest .
# The run: CONFIG (a path inside the image) and RUN_NAME below. The first start creates /data/runs/$RUN_NAME;
# a restarted pod continues it in place (colosseum hub --resume); after the budget the pod idles instead of
# being restarted into a finished run.
apiVersion: v1
kind: Namespace
metadata:
  name: colosseum
  labels:
    app.kubernetes.io/name: colosseum
---
apiVersion: v1
kind: Service
metadata:
  name: colosseum-hub
  namespace: colosseum
  labels:
    app.kubernetes.io/name: colosseum
    app.kubernetes.io/component: hub
spec:
  type: ClusterIP            # LoadBalancer / NodePort to let machines outside the cluster join
  selector:
    app.kubernetes.io/name: colosseum
    app.kubernetes.io/component: hub
  ports:
    - name: hub
      port: 47100
      targetPort: hub
      protocol: TCP
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: colosseum-hub
  namespace: colosseum
  labels:
    app.kubernetes.io/name: colosseum
    app.kubernetes.io/component: hub
spec:
  serviceName: colosseum-hub
  replicas: 1                # one hub per run (no hub HA, spec section 2)
  selector:
    matchLabels:
      app.kubernetes.io/name: colosseum
      app.kubernetes.io/component: hub
  template:
    metadata:
      labels:
        app.kubernetes.io/name: colosseum
        app.kubernetes.io/component: hub
    spec:
      terminationGracePeriodSeconds: 40     # > distributed.shutdown_grace_sec (20): final snapshots arrive
      containers:
        - name: hub
          image: colosseum-hub:latest
          imagePullPolicy: IfNotPresent
          env:
            - name: CONFIG
              value: configs/examples/unit_harvest_league.yaml
            - name: RUN_NAME
              value: league
            - name: XDG_DATA_HOME           # the hub identity lives on the volume: the token survives restarts
              value: /data/xdg-data
            - name: XDG_CACHE_HOME
              value: /data/xdg-cache
            - name: OMP_NUM_THREADS
              value: "1"
          command: ["/bin/sh", "-c"]
          args:
            - |
              set -u
              run="/data/runs/${RUN_NAME}"
              if [ -f "${run}/run.json" ]; then
                colosseum hub --resume "${run}"
              else
                colosseum hub -c "${CONFIG}" --set run.dir=/data/runs --set "run.name=${RUN_NAME}"
              fi
              code=$?
              if [ "${code}" -eq 0 ]; then
                echo "colosseum: the run reached its budget; idling (scale the StatefulSet to 0 to stop)"
                exec sleep infinity
              fi
              exit "${code}"
          ports:
            - name: hub
              containerPort: 47100
              protocol: TCP
          readinessProbe:
            tcpSocket:
              port: hub
            periodSeconds: 10
          resources:
            requests:
              cpu: "2"
              memory: 4Gi
            limits:
              memory: 8Gi
          volumeMounts:
            - name: data
              mountPath: /data
  volumeClaimTemplates:
    - metadata:
        name: data
      spec:
        accessModes: ["ReadWriteOnce"]   # SQLite WAL needs a local (block) volume, not NFS
        resources:
          requests:
            storage: 20Gi
```

### Proposed rulings (what — why — cost if wrong)

1. **SSH links run `ssh -T -o BatchMode=yes -o ExitOnForwardFailure=yes -o LogLevel=INFO -o ServerAliveInterval=10 -o ServerAliveCountMax=3`, user options only as `--ssh-opt Key=Value` (passed as `-o`)** — the hub cannot answer prompts; `LogLevel=INFO` guarantees the `Allocated port` line even with a quieter `~/.ssh/config`; keepalives detect a dead link within ~30 s; `-o` only keeps arbitrary arguments (and `ProxyCommand` with shell metacharacters) out of the hub's command line — cost: an unknown host key needs one manual `ssh` (or `--ssh-opt StrictHostKeyChecking=accept-new`), documented; exotic options with spaces cannot be passed (use `~/.ssh/config`).
2. **The remote node lives as long as the ssh link** (`COLOSSEUM_SSH_SESSION`: stop at stdin EOF) — without it a dropped link leaves a node agent whose forwarded hub address is dead, and the restarted link starts a second agent of the same identity on the machine — cost: a short SSH outage restarts the remote node's processes (its cells and unfinished matches are dropped as for any lost node; learners there restart from their recovery point).
3. **ssh runs in its own session and is stopped by the hub at the end of the distributed stop; `PR_SET_PDEATHSIG` covers a killed hub on Linux** — Ctrl+C in the hub's terminal must not cut the tunnel before the remote learner's final snapshot arrived — cost: on macOS a killed hub leaves ssh running until the remote node stops after `hub_lost_timeout_sec` (documented).
4. **`update-code` keeps the node agent process and spawns its children on the new bundle (`child_code`) instead of re-executing the agent** — a re-exec kills every child (they die with the node), so learners whose code did not change could not keep running, which spec 6.4 requires; the code the node agent runs is protected by refusing any change of `colosseum/{net,node,hub,bootstrap}/` and `colosseum/core/types.py` (needs `hub --resume`, after which nodes update themselves) — cost: a node agent keeps its old code until its next start (by construction only protocol-identical code), and the update path patches `multiprocessing.spawn.get_preparation_data` (a private hook, one function, covered by `test_sp5_child_code.py`).
5. **"Code the hub runs" = every `colosseum` module loaded in the hub process + the protocol packages + the module file of `matchmaking.matchmaker_class`; project modules otherwise are not hub code** — the hub imports bots, models and envs while validating, but runs none of them; the game itself is checked by the `GameSpec` / role-signature comparison of a child on the new bundle — cost: conservative refusals for `colosseum` changes in modules the hub imported only incidentally (restart with `--resume`); a project helper imported by a custom matchmaker is not detected (documented).
6. **A learner restart for `update-code` uses a fresh recovery point (`stop_learner` with `reason="restart"`), not the final snapshot** — spec 6.4 says «с точки восстановления», and a final snapshot per update would grow the pool — cost: none (the recovery point is written at the stop, so nothing is lost).
7. **Node requirements changed → `update-code` refuses** — the nodes' environments are built per requirements hash at join time; changing them under running children is a different operation — cost: a dependency change needs `hub --resume` (nodes rebuild their env themselves).
8. **One worker per node drains at a time (agent additions and code updates); a drain waits for every episode running at the `Drain` message, at most `DRAIN_TIMEOUT_SEC` (300 s); episodes started meanwhile are abandoned** — keeps the node's throughput, needs no change to `RolloutLoop`'s loop (R4) — cost: an env whose episode ended first plays an abandoned episode until the worker exits (wasted env steps: at most about one episode per env per restart, counted in the budget).
9. **A grant naming an agent the target worker was not built with is held until that worker restarts** — the hub does not track per-worker agent sets; the node does — cost: a few grants of the old incarnation are discarded.
10. **A frozen trainable agent is seated as a fixed player of the league that plays `ckpt_v<N>`; it meets others only as an anchor** (`anchors: null` includes it automatically; explicit lists need `--anchor-weight`); its older snapshots are no longer drawn — the spec makes it "a frozen entity `X@v<N>`" and stops its cells; the matchmaker's fixed-player path is the one that seats such entities — cost: owners with explicit anchor lists stop meeting X unless `--anchor-weight` is given (the reply says so).
11. **Freezing waits for the final snapshot up to `distributed.shutdown_grace_sec`, then uses the newest stored snapshot (WARNING); with no snapshot at all the freeze is aborted and the agent stays active** — the final is the agent's true last state; a lost node must not block the command — cost: a freeze of an agent whose node is gone uses an older snapshot.
12. **Freezing or removing the last active trainable agent is refused** — the run's budget advances only through training cells (spec 4.2: no training cells without a collecting agent), so the run would never end — cost: the user adds another agent first or stops the run.
13. **`agents add` of an id that ever existed is refused, removed ids included** — an agent id names a rating lineage and a snapshot dir; reusing it would mix two agents' histories — cost: a re-added agent needs a new id (as ARENA_GUIDE already advises for changed bots).
14. **Agent commands are refused with `match_refresh_interval_sec: 0` (all three, not only `add`) and on `hub --idle`** — static lineups never change, so neither a freeze nor a removal could take effect (a frozen agent's collecting seats would feed a stopped learner); an idle hub has no training — cost: none.
15. **The LR progress of an agent added at S runs as `(env_steps − S) / (total_timesteps − S)`; its share / anchor schedules use `env_steps − S`; kickstart λ already decays by the learner's own train steps** — "schedules from the agent's start point" (spec 6.3), and its LR schedule then ends with the run — cost: a late agent's LR decays faster than the first agents' did.
16. **`agents add` uploads every existing local path of the fragment (`path`, `init.from`, `kickstart.teacher`) to the hub; values that are not local paths pass unchanged (agent names, hub-side paths)** — spec 6.2 says local files go to the hub; a name is not a file — cost: a value that is both a local path and meant as a hub-side path is uploaded (harmless).
17. **Resume with `-c` (spec 5.4): the config is the agent set** — agents of the saved set that the config lists are active again (WARNING when they were frozen / removed), their start points kept; saved agents the config lacks become `removed`; the anchor overrides of `agents …` are dropped (WARNING) — the spec says the new config wins — cost: a user who resumes with the original config re-activates agents frozen on the fly (the WARNING names them).
18. **The hub's K8s pod idles (`sleep infinity`) after a run reached its budget** instead of exiting — a StatefulSet restarts exited pods, and a restarted hub resumes at the budget (WARNING, nothing to train) in a loop — cost: the user scales the StatefulSet to 0 (documented).
19. **Each K8s node pod is a new node** (identity in an `emptyDir`) — Deployments are for scaling; a StatefulSet of nodes would keep identities at the price of ordered scaling — cost: `nodes.json` grows by one record per pod start (records are small; `nodes remove` cleans up).
